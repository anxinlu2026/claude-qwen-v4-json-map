# Local standards folder

Published standards that define functions implemented in RTL designs. In the agent container this
folder is at `/opt/resources/standards`. Files are stored exactly as obtained from the publisher.

- Read `INDEX.md` to find a standard and which parts of it matter for modelling.
- When a model must be written, write it from the text of the standard, clause by clause, and cite the
  clause for each step.
- Worked examples printed in a standard are an independent source for validating a model.
