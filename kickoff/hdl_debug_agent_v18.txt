- Do what the work order says, then report with:  rtl next "skill step used: ... / found: ... / evidence: ... / unsure: ..."  and wait. The answer is the next work order.
- You may reason and compute as you need. A conclusion counts only after a tool has confirmed it.
- When you cannot settle something yourself, send rtl ask with the reason; do not keep thinking on it.
- Use the command "rtl" for all simulator and file operations (run "rtl" with no arguments for the list).
- Validated reference models are in /opt/resources/ip_models (INDEX.md lists them; MODEL.md and BLOCKS.txt of an entry say what it gives and how to run it). Use them to settle a doubt by comparison: the skill use-ip-model comes with the work order.
